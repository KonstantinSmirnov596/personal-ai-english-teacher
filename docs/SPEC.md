# Промпт-ТЗ: open-source версия голосового тренажёра для испано- и португалоязычных

Документ для Claude Code. Он описывает, как из готового личного приложения (отчёт `project_report.md`) сделать публичный проект на GitHub для самостоятельной установки. Учащиеся говорят на латиноамериканском испанском или бразильском португальском. Собеседник по-прежнему говорит только на американском английском.

## Как запустить

1. Создайте пустую папку, например `C:\CLAUDE_PROJECTS\voice-tutor-oss`, и положите в неё этот файл как `docs/SPEC.md`, а отчёт исходного проекта как `docs/BASELINE_REPORT.md`.
2. Во вкладке Code выберите окружение Local, папку — эту новую. Если Claude Code попросит доступ к папке исходного проекта, разрешите только чтение.
3. Отправьте стартовый промпт из конца этого файла.

## 2. Режим работы

Те же правила, что в исходном проекте:

- Работа идёт по этапам с машинной приёмкой: `scripts/check_stage.ps1 <N>` возвращает 0, а в `docs/reports/` лежит отчёт этапа.
- Решения внутри этапа принимаешь сам и записываешь в `docs/PROGRESS.md` с причиной.
- Вопросы к владельцу копятся в `docs/HUMAN_TASKS.md` и задаются одним сообщением в конце этапа.
- Версии пакетов, флаги, параметры API, лицензии и требования к драйверам сверяешь по официальным источникам и записываешь ссылку. По памяти не утверждаешь.
- Проверки не ослабляются ради прохождения. После трёх неудачных подходов записываешь, что пробовал, и переходишь к следующему пункту.

Первым делом создай `CLAUDE.md` (до 200 строк), `docs/PLAN.md`, `docs/PROGRESS.md`, `docs/HUMAN_TASKS.md` и `.claude/settings.json` по образцу исходного проекта, с учётом этого ТЗ.

## 3. Исходная база

Код берётся из исходного проекта и дорабатывается. С нуля ничего не переписывается без причины, записанной в «Решениях».

Что переносится:

- `trainer/`, `web/`, `scripts/`, `tests/`, `pyproject.toml`, `uv.lock`;
- `docs/protocol.md`, `docs/testing.md`, `docs/design.md`;
- макеты `docs/ui/`.

Что не переносится:

- `.git` (история начинается с чистого коммита);
- `.venv`, кэши, `test-results`, сгенерированные фикстуры;
- `.claude/settings.local.json`, `CLAUDE.local.md`;
- любые файлы с данными владельца.

Чистка после переноса (отдельный пункт этапа 0, с тестом):

- В репозитории не остаётся имён, путей пользователя Windows, адресов почты, ключей, токенов и записей голоса. Тест ищет шаблоны: `C:\\Users\\`, адреса почты, `sk-`, строки длиннее 30 символов из base64-алфавита, файлы `.wav` вне сгенерированных каталогов.
- Русский текст остаётся только там, где он нужен как данные ru-локали, если она сохраняется (см. раздел 5). В коде, комментариях и документации его нет; тест ищет кириллицу вне разрешённых путей.
- Упоминания конкретного владельца, его ноутбука и его сценариев убираются из документации.

## 5. Языки учащегося

### Варианты языка

- Испанский — нейтральный латиноамериканский: обращение на «tú», без «vosotros» и испанских регионализмов, без «voseo». Пример стиля: «Graba tu respuesta», «Configuración».
- Португальский — бразильский: обращение «você», бразильская лексика и орфография. Пример: «Grave sua resposta», «Configurações».

### Переключение

- При первом запуске язык предлагается по региональным настройкам Windows (`es-*` → испанский, `pt-*` → португальский, остальное → испанский) и подтверждается пользователем на первом шаге мастера.
- Затем язык меняется вручную: «Configuración → Idioma / Configurações → Idioma». Переключатель — два варианта, без автоопределения по речи.
- Переключение меняет сразу: язык интерфейса, язык правок и пояснений, язык переводов и «Как сказать?», каталог ошибок произношения, тексты советов и подсказок, набор фраз для «Чтения» (если наборы различаются).
- Переключение без перезапуска приложения. История прошлых сессий остаётся на том языке, на котором создавалась.

### Что на каком языке

| Что | Язык |
| --- | --- |
| Речь и текст собеседника, подсказки вариантов ответа, фразы для «Чтения», примеры в правках | Американский английский |
| Интерфейс, пояснения правок (`note_l1`), главный вывод итогов, переводы, советы по произношению, сообщения об ошибках | Язык учащегося |
| Код, идентификаторы, комментарии, журналы, сообщения коммитов | Английский |

Текст на языке учащегося никогда не уходит в синтез речи. Существующая проверка «нет кириллицы перед синтезом» заменяется проверкой языка: перед синтезом предложение проверяется детектором языка или списком частотных слов es/pt; при срабатывании предложение не озвучивается и пишется предупреждение в журнал. Ложные срабатывания на английских предложениях с испанскими именами и названиями проверяются тестом.

### Расширяемость

Язык учащегося описывается набором файлов, без изменений кода:

- `web/i18n/<lang>.js` — строки интерфейса;
- `voicetutor/data/l1/<lang>/catalog.json` — каталог ошибок произношения;
- `voicetutor/data/l1/<lang>/patterns.json` — названия и подсказки ключей ошибок;
- `voicetutor/data/l1/<lang>/reading_phrases.json`, если набор фраз отличается;
- `voicetutor/data/l1/<lang>/meta.json` — название языка на нём самом и по-английски, для подстановки в промпты.

Русская локаль из исходного проекта в публичную версию не входит. Если перенести её дешевле, чем удалить, она остаётся как третий язык, проходит те же проверки полноты и упоминается в README как дополнительная; решение записывается в «Решения».

### Промпты

Промпты собеседника, корректора, итогов и помощников переводятся с русской привязки на параметр:

- `{{l1_name_en}}` — `Latin American Spanish` или `Brazilian Portuguese`;
- поле `note_ru` переименовывается в `note_l1` (протокол, схемы, база данных с миграцией);
- корректор получает описание типичных ошибок говорящих на этом языке в виде списка ключей с пометкой языка;
- пример в промпте корректора — свой для каждого языка (типичная ошибка: для испанского «I have 30 years», для португальского «In my city has a big park»).

## 7. Железо

### Минимальные требования

Требования выбраны так, чтобы стек исходного проекта (faster-whisper turbo, Kokoro-82M, wav2vec2 lv-60 espeak, torch с CUDA 12.8) работал без замены моделей. Поддержка видеокарт AMD, Intel, Apple и режима только на процессоре в первую версию не входит.

| Компонент | Минимум | Рекомендуется | Обоснование |
| --- | --- | --- | --- |
| ОС | Windows 10 22H2 или Windows 11, x64 | Windows 11 | Окно приложения — Edge в режиме `--app`; Edge есть в системе по умолчанию |
| Видеокарта | NVIDIA с 6 ГБ видеопамяти, архитектура Turing или новее (GTX 1660, RTX 2060, RTX 3050 8 ГБ, RTX 3060 / 4050 / 5050 Laptop 6 ГБ и выше) | NVIDIA с 8 ГБ и больше | Три модели в исходном проекте занимают 4,4 ГБ; профиль «Compacto» (ниже) должен укладываться в 5 ГБ с запасом под рабочий стол |
| Драйвер NVIDIA | Версия, поддерживающая CUDA 12.8 | Последний стабильный | Сборка torch `cu128` и библиотеки cuBLAS/cuDNN из неё. Точную минимальную версию для Windows взять из release notes CUDA 12.8 и записать в документацию и проверку установщика |
| Процессор | 4 ядра x64 | 6–8 ядер | Нагрузка в основном на видеокарте |
| ОЗУ | 16 ГБ | 16 ГБ и больше | Загрузка моделей и окно Edge одновременно; уточнить замером пикового потребления |
| Диск | 15 ГБ свободно, SSD | 20 ГБ | Окружение с torch, модели около 3,2 ГБ, кэш пакетов |
| Микрофон | Любой | Гарнитура или наушники | Перебивание голосом работает только в наушниках |
| Сеть | Для установки и запросов к LLM | — | Звук не передаётся; облачная LLM получает только текст |

Пункты, которые Claude Code обязан подтвердить на этапе 0 по официальным источникам и записать в `docs/reports/stage0.md`:

1. Какие вычислительные архитектуры (compute capability) входят в сборки torch `cu128` и CTranslate2 для Windows выбранных версий. Если Turing (sm_75) не поддерживается, минимум поднимается до Ampere, и это отражается во всех документах.
2. Минимальная версия драйвера NVIDIA для Windows под CUDA 12.8.
3. Поддержка `float16` и `int8_float16` в CTranslate2 на минимальной архитектуре.

### Профили

Профиль определяет, как модели размещаются в видеопамяти. Выбирается мастером первого запуска по замерам, может быть изменён вручную в «Configuración → Rendimiento / Configurações → Desempenho».

| Профиль | Условие | Распознавание | Фонемная модель | Прочее |
| --- | --- | --- | --- | --- |
| `completo` | Свободно не меньше 7 ГБ видеопамяти | turbo, `float16` | `float16`, держится в памяти | Как в исходном проекте |
| `compacto` | Свободно от 5 до 7 ГБ | turbo, `int8_float16` | `float16`, загружается при входе в «Чтение» или при первой оценке в разговоре и выгружается после 5 минут простоя | Пометки произношения в разговоре по умолчанию выключены |
| не поддерживается | Меньше 5 ГБ свободно, нет NVIDIA, драйвер или архитектура ниже минимума | — | — | Окно объясняет причину, что можно сделать и где в документации требования. Приложение не падает |

Свободная видеопамять измеряется с учётом того, что уже занято рабочим столом и другими программами. Если она меняется (запущена игра), ядро при нехватке памяти выгружает фонемную модель, а при ошибке нехватки в распознавании показывает понятное сообщение и предлагает закрыть другие программы; падения процесса быть не должно.

Приёмка профилей на машине разработки (RTX 5060 Laptop, 8 ГБ):

- `compacto`: пиковое потребление видеопамяти процессом ядра за полный сценарий (разговор 10 реплик + «Чтение» 5 фраз) не больше 5,0 ГБ по `nvidia-smi`;
- оба профиля проходят наборы `gpu` и `e2e` и цели задержки исходного проекта;
- точность распознавания на петле TTS → STT в `compacto` хуже `completo` не больше чем на 2 процентных пункта WER.

### Мастер первого запуска

Открывается при первом запуске и из настроек («Volver a ejecutar el asistente / Executar o assistente novamente»). Каждый шаг можно пройти заново, кроме шагов, которые выполняются только при установке.

1. **Язык.** Выбор испанского или португальского; весь мастер дальше на выбранном языке.
2. **Проверка оборудования.** Видеокарта, видеопамять всего и свободно, версия драйвера, compute capability, ОЗУ, свободное место на диске, питание от сети или батареи. Итог: подходящий профиль или «не поддерживается» с причинами по каждому пункту и ссылкой на раздел документации.
3. **Модели.** Если модели не скачаны при установке — загрузка с прогрессом, докачкой после обрыва и проверкой контрольных сумм.
4. **Замер.** Около минуты: распознавание фикстуры, синтез фразы, оценка произношения фразы. Показываются задержки и использованная видеопамять. По результату подтверждается или понижается профиль: если в `completo` задержка до первого звука на моке без задержки больше 1,2 с или свободной памяти после загрузки меньше 0,8 ГБ, предлагается `compacto`.
5. **Микрофон.** Выбор устройства, волна, 3 секунды тишины для измерения шума, затем фраза для проверки уровня. По уровню шума выставляются порог детектора речи и значение шумоподавления по умолчанию. Если сигнала нет — подсказка, как дать доступ к микрофону в Windows и Edge.
6. **Звук и голос.** Тестовая фраза в динамики, выбор голоса и скорости, вопрос «¿Usas auriculares? / Você usa fones de ouvido?» для перебивания голосом.
7. **Подключение LLM.** Шаблоны из раздела 11; ключ вводится в поле окна и сразу проверяется. Шаг можно пропустить, тогда разговор недоступен до добавления подключения, а «Чтение» работает.
8. **Уровень.** A2, B1, B2, C1 с короткими описаниями на языке учащегося.

Результаты замеров хранятся в базе (таблица `hardware_profile`: дата, видеокарта, драйвер, профиль, замеры) и показываются в настройках. Мастер не отправляет никаких данных наружу.

Предупреждения во время работы:

- Ноутбук на батарее — одноразовое уведомление, что задержка может вырасти.
- Обновился драйвер или сменилась видеокарта — при следующем запуске предлагается повторить шаги 2 и 4.

## 8. Дистрибуция: нужен ли exe

**Решение: exe не нужен.** Публикуются исходный код и релиз с архивом и скриптом установки; инструкции на трёх языках.

Причины:

- **Объём.** Окружение с torch и CUDA-библиотеками и модели вместе занимают несколько гигабайт, а [GitHub ограничивает каждый файл релиза размером меньше 2 ГиБ](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases). Самодостаточный exe пришлось бы резать на части или хранить вне GitHub.
- **Установщик уже есть.** `setup.ps1` исходного проекта ставит uv, окружение по lock-файлу, модели и ярлык без прав администратора, повторный запуск безопасен. exe дублировал бы это.
- **Подпись.** Неподписанный exe вызывает предупреждение SmartScreen и чаще блокируется антивирусами; сертификат подписи кода — расход и процедура, которых у личного open-source проекта нет. Скрипты в репозитории открыты для проверки.
- **Обновления.** Модели и окружение остаются между версиями в каталоге данных; обновление кода — замена небольшого архива.

Что публикуется в релизе:

- `VoiceTutor-<версия>.zip` — код без моделей и окружения;
- `SHA256SUMS.txt`;
- примечания к выпуску на трёх языках.

Порядок установки для пользователя:

1. Скачать архив релиза, распаковать в папку без кириллицы и пробелов в пути (проверяется установщиком; если путь неподходящий — понятное сообщение).
2. Двойной щелчок по `install.cmd`.
3. `install.cmd` запускает `scripts\setup.ps1` через `powershell -NoProfile -ExecutionPolicy Bypass -File`, без изменения политики системы.
4. `setup.ps1`:
   - проверяет минимальные требования (раздел 7) до загрузки чего-либо и останавливается с понятным сообщением, если они не выполнены;
   - скачивает uv закреплённой версии с GitHub-релиза Astral и проверяет SHA-256 из репозитория (не через `irm | iex`);
   - ставит Python 3.12 через `uv python install`, системный Python не нужен;
   - ставит зависимости по `uv.lock`;
   - скачивает модели с Hugging Face по закреплённым ревизиям (хэш коммита), с докачкой и проверкой SHA-256;
   - скачивает шрифты и детектор речи с проверкой sha512, как в исходном проекте;
   - создаёт ярлык в папке приложения, на рабочем столе и в меню «Пуск» — последние два с подтверждением в консоли;
   - запускает приложение, открывается мастер первого запуска.
5. `uninstall.cmd` удаляет ярлыки и окружение; данные пользователя (`%LOCALAPPDATA%\VoiceTutor`) удаляются только после явного подтверждения.
6. Обновление: распаковать новый архив поверх или рядом и запустить `install.cmd`; данные и модели сохраняются.

Проверить на этапе 4:

- Архив, скачанный из интернета, получает пометку Mark of the Web. Тест присваивает её копии архива (поток `Zone.Identifier`) и проверяет, что установка проходит; поведение SmartScreen для `install.cmd` документируется со скриншотами и инструкцией на трёх языках.
- Установка в путь с пробелами и с неанглийскими буквами: либо работает, либо отклоняется с понятным сообщением до начала загрузки.
- Установка без интернета после частичной загрузки: повторный запуск докачивает.

Условие пересмотра: если по issue станет видно, что пользователи массово не справляются со скриптом, отдельной задачей делается маленький установщик (Inno Setup или аналог), который выполняет тот же `setup.ps1`. В первую версию это не входит.

## 10. Публичный репозиторий

### Лицензии

Аудит до публикации, результат в `THIRD_PARTY_NOTICES.md` и в отчёте этапа: для каждой зависимости, модели, шрифта и бинарного компонента — лицензия по первоисточнику (страница модели на Hugging Face, файл LICENSE в репозитории), ссылка, что распространяется в репозитории и релизе, что скачивается у пользователя.

Особое внимание:

- espeak-ng распространяется под GPL-3.0. Бинарные файлы espeak-ng в репозиторий и архив релиза не кладутся; они ставятся у пользователя из пакета зависимостей. Совместимость выбранной лицензии кода с таким использованием записывается в отчёт как вопрос к владельцу, без юридического вывода от Claude Code.
- Веса моделей в репозиторий и релиз не кладутся, только скачиваются при установке.
- Шрифты (OFL) и детектор речи скачиваются при установке, как в исходном проекте, либо кладутся в репозиторий с их лицензиями — решение по результату аудита.

### Конфиденциальность

- Никакой телеметрии, аналитики, отчётов о сбоях и проверки обновлений. Единственный внешний обмен во время работы — запросы к выбранному LLM-провайдеру; сетевой тест исходного проекта сохраняется.
- Журналы не содержат текста реплик по умолчанию; режим подробного журнала включается в настройках и предупреждает, что туда попадёт текст.

### GitHub

- CI на `windows-latest`: `ruff`, набор `fast`, проверка полноты i18n, проверка JSON по схемам, проверка ссылок в документации, поиск секретов и личных данных. Видеокарты в CI нет: наборы `gpu` и `e2e` запускаются локально скриптом `scripts\check_release.ps1`, его итог прикладывается к описанию релиза.
- Шаблоны issue на трёх языках: ошибка (с полями: видеокарта, видеопамять, драйвер, профиль, версия, выдержка журнала), предложение; шаблон pull request на английском.
- `scripts\collect_diagnostics.ps1` собирает архив для issue: версии, профиль, журналы без текста реплик и без ключей; тест проверяет отсутствие ключа-маркера в архиве.
- Публикация в GitHub (создание репозитория, push, релиз) выполняется только по явной команде владельца; до этого — локальный репозиторий и черновик примечаний к выпуску.

### Новый тип ошибки: вставка звука

Исходная оценка находит замены и пропуски. Для `s_cluster_epenthesis`, `final_epenthesis` и `ed_suffix` нужна вставка гласной. Расширение метода:

- в набор конкурентов для позиции между фонемами добавляются гипотезы со вставленной гласной (e, ɛ, i, ɪ, ə — по каталогу);
- оценка — то же отношение правдоподобий CTC на окне, что и для замен;
- диагноз выдаёт `heard` вида `+e` перед позицией, интерфейс показывает лишний звук в разборе слова;
- вставки проверяются только в позициях, указанных в каталоге, чтобы не умножать ложные срабатывания.

Фикстуры с акцентом: Kokoro принимает на вход фонемную строку; «акцентные» варианты (espeak, bigi, berry вместо very) синтезируются из изменённых фонем во фразах-носителях. Если Kokoro не воспроизводит нужный звук (испанская «jota», раскатистое r), запись помечается как непроверяемая на синтезе, как в исходном отчёте.

Приёмка (на синтезированной речи трёх американских голосов, отдельно по каждому языку учащегося):

| Метрика | Цель |
| --- | --- |
| Ложные «ошибки» на верном чтении всех фраз | до 3 % звуков |
| Подмена или вставка из каталога помечена «ошибкой» | от 80 % случаев, по всем проверяемым записям вместе |
| Прозвучавший звук назван верно | от 60 % |
| Записи, где метод ненадёжен | перечислены в отчёте с процентами, как в исходном отчёте |
