# Personal AI English Teacher 0.1.1

## English

Installer fix. In 0.1.0 the installer could stop right after installing Python with "Python was installed but uv cannot find it": Windows PowerShell sometimes ended the `uv python find` step early and read its exit code as a failure. The installer now waits for the step to finish. Nothing else changed.

If 0.1.0 stopped at that step for you, extract 0.1.1 over the same folder and run `install.cmd` again: it continues where it stopped. If 0.1.0 installed fine, you do not need this update.

Install: download `EnglishTeacher-0.1.1.zip`, check it against `SHA256SUMS.txt`, unblock and extract it to a short path such as `C:\EnglishTeacher`, and double-click `install.cmd`.

This is a pre-release: the Spanish and Portuguese texts have not been proofread by native speakers yet, and it was tested on one graphics card (GeForce RTX 5060 Laptop, 8 GB). Reports are welcome in Issues.

Esta é uma versão preliminar: os textos em espanhol e português ainda não foram revisados por falantes nativos, e ela foi testada em uma única placa de vídeo (GeForce RTX 5060 Laptop, 8 GB). Você pode relatar problemas em Issues.
